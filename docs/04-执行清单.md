# 04 · 执行清单

> 按顺序打勾。跳过任何一步，方案都有洞。

## 阶段一：采购与准备

硬件（树莓派为**推荐配置，非必需** —— 应急时可用闲置手机永久离线
+ 气隙签名应用替代，见 [01](./01-生前流程.md) 1.1 节末尾）：

- [ ] 树莓派 Zero v1.3（**不带无线版本**）× 1
- [ ] Waveshare 1.3 寸 LCD HAT × 1
- [ ] 树莓派摄像头模块 × 1
- [ ] microSD 卡（16GB+）× 1 + 读卡器
- [ ] 304 不锈钢板 × 1 + 3mm 钢字码冲子套装（或成品助记词钢板套件）
- [ ] 过塑机 + 过塑膜（或去文印店过塑）
- [ ] 激光打印机（打印 Vault 密码，喷墨会晕染）

软件与工具（与硬件一样，都是要准备的材料）：

- [ ] SeedSigner 镜像（官网 seedsigner.com 免费下载，自行校验签名）
- [ ] Sparrow 钱包（官网 sparrowwallet.com 免费下载，自行校验签名）
- [ ] 本地加密登记工具（可选；用于记录位置/步骤并导出 `.vault` 加密备份。
      本方案只依赖其导出格式，不绑定具体产品；也可用纸笔 + 独立加密压缩包替代）

## 阶段二：搭建与验证（小额！）

- [ ] SeedSigner 镜像下载 → 校验 SHA256 + GPG → 刷机 → 组装
- [ ] Sparrow 下载 → 校验 GPG 签名 → 新建观察钱包
- [ ] 生成种子（骰子/摄像头/随机三选一）
- [ ] 钢板敲制 → **照着钢板实际恢复一次**验证
- [ ] 打印 SeedQR → 过塑 → 扫码验证可读
- [ ] 设定 BIP39 口令（50 字符内、纯 ASCII、机器随机）
- [ ] **转一笔小额（如 $50 等值）完整走一遍**：收币 → 花币（QR 流程）→ 用 SeedQR 恢复验证
- [ ] 确认全流程无误后，再转入大额

## 阶段三：Vault 与分发

- [ ] 登记 App 中建条目：存放位置 + 取用步骤 + BIP39 口令 + 恢复教程附件
- [ ] 教程截图一律用**测试钱包**（真实密钥永不出现在截图里）
- [ ] 导出 `.vault`，打时间戳
- [ ] Vault 密码：机器生成 14+ 位真随机，激光打印 + 过塑，一式三份
- [ ] 存放（遵守铁律：种子与密码永不同地）：
  - [ ] 种子材料 → 家里保险柜 / 银行保险箱 / 老家藏匿
  - [ ] Vault 密码 → 亲属A家 / 亲属B家（盲存：只说重要，勿说用途）/ 律师处
  - [ ] Vault 文件 → 家人手机各一份 / 银行·律师兜底一份 / 亲属家盲备份一份
- [ ] 填写《身后流程》手册中的括号部分（联系人、地址）
- [ ] 通知家人删除旧版 vault（如有）

## 阶段四：年度演练（每年一次）

- [ ] 离线机上用钢板 + 口令恢复，核对首个地址一致
- [ ] SeedQR 扫码验证
- [ ] 解密一份 vault 备份，确认密码纸条字迹清晰
- [ ] 检查三处存放点完好（受潮/搬家/褪色）
- [ ] 家人实操一遍"解密 vault → 读教程"
- [ ] 钱包有变动则重新导出分发 vault
