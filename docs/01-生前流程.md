# 01 · 生前流程

> 目标：币安全地躺着，你能方便地花，家人不需要懂。

## 一、搭建设施

### 1.1 签名器：SeedSigner（推荐配置，非唯一选择）

推荐用自攒的 SeedSigner（树莓派），理由是它的无线硬件**物理不存在**，
air gap 最纯粹。但它不是必需品 —— 见本节末尾的应急替代方案。

采购清单（约 50–70 美元）：

- 树莓派 Zero **v1.3（不带无线版本）** —— 物理上没有 WiFi/蓝牙芯片才是真 air gap，Zero W / 2W 不要
- Waveshare 1.3 寸 LCD 显示 HAT（240×240，自带摇杆按键）
- 树莓派摄像头模块（v1.3 或 v2，用于扫二维码）
- microSD 卡 + 读卡器

刷机流程：

1. 从官网下载镜像（seedsigner.com → GitHub releases）
2. **校验 SHA256 和 GPG 签名** —— 这是你唯一需要信任的环节
3. 刷入 SD 卡，组装，开机
4. 该设备**永不联网**，**永不插 USB**（供电用充电宝或 USB 充电器即可）

SeedSigner 是 stateless 的：种子只活在内存里，断电即擦除。
设备丢了=丢了一块电路板，币还在链上。

**应急替代（不推荐长期使用）**：没有树莓派时，可用一部闲置手机
永久离线（恢复出厂、永不插卡、永不连 WiFi）+ 同类气隙签名应用
（如 AirGap Vault），同样走二维码与 Sparrow 交互，流程不变。
不推荐的原因：手机的无线模块是"软件关闭"而非物理不存在，
且存在闭源基带固件，air gap 的纯度低于无无线版树莓派。
仅作应急，条件允许时回归推荐配置。

### 1.2 观察钱包：Sparrow（联网电脑）

1. 从官网下载 Sparrow，**校验 GPG 签名**（Craig Raw 的 key）
2. 新建钱包 → 选择"观察钱包"，导入主公钥（xpub）
3. 日常只用它看余额、生成收款地址、构造交易 —— 它没有私钥，转不走币
4. 建议连自己的 Electrum 服务器（隐私），没有也可用公共服务器起步

### 1.3 生成种子（三选一，按偏执程度排序）

- 省事：SeedSigner 内置随机生成
- 偏执：骰子摇 100+ 次，手动输入
- 折中：SeedSigner 用摄像头拍一张混乱照片取熵

生成后立即做两件事（见 1.4 / 1.5），**不要先转大钱**。

### 1.4 钢板：最后防线

- 304 不锈钢板 + 3mm 钢字码冲子（A-Z + 数字），或成品套件（Keystone Tablet / Billfodl，字母片自行拼装）
- BIP39 的 2048 个单词**前 4 字母唯一**，只敲 `序号 + 前4字母`（如 `07-ABAN`），24 行
- **绝对不要把种子发给商家激光雕刻** —— 等于把钥匙复印给陌生人
- 敲完后照着钢板**实际恢复一次**，确认每个词唯一可识别、顺序正确，再封存

### 1.5 SeedQR：常用工具

- SeedSigner 可把种子导出为 SeedQR（二进制二维码）
- 打印出来，**过塑**（二维码自带纠错，30% 损坏可读）
- 放在隐秘但可取用的地方 —— 这是你日常签名的"钥匙"，与钢板分开放
- 坏了重印一张即可（种子还在钢板上）

### 1.6 BIP39 口令（第 25 个词）

- 只记在脑子里，不写下来，不进任何数字设备（除了加密 vault，见下）
- 50 字符以内、纯 ASCII、机器随机或 4–5 个随机单词拼接
- 区分大小写，首尾不要空格
- **忘了=丢币**，没有找回。这是整个方案里唯一无解的单点，靠年度演练对抗遗忘

## 二、日常花币（QR 流程，全程约 1 分钟）

1. Sparrow（观察钱包）构造交易 → 显示**动态二维码**
2. SeedSigner 摄像头扫入 → 在小屏幕上**核对地址和金额**
3. 输入 BIP39 口令 → 签名 → 显示签好名的二维码
4. Sparrow 扫回 → 广播

## 三、Vault 维护

- 每次钱包变动（新地址、大额转入、换口令、搬钢板）后：
  1. 在登记 App 中更新条目，重新导出 `.vault`
  2. 分发给所有家人（以**时间戳**验新）
  3. 通知家人删除旧版
- Vault 内容：BIP39 口令（不完整因子，可放）+ 存放位置 + 恢复教程附件
- Vault 里**永不放**：助记词原文、私钥、完整登录密码

## 四、年度演练（不演练的备份=没有备份）

每年一次，离线环境：

1. 用钢板 + 口令在离线机恢复钱包，验证首个地址与 Sparrow 一致
2. 扫 SeedQR，确认可读
3. 解密一份 vault 备份，确认密码纸条字迹清晰、文件可解
4. 检查三处存放点是否完好（受潮、搬家、字迹褪色）
5. 让一位家人实际操作一遍"解密 vault → 读教程"（用测试 vault 或在监督下）
