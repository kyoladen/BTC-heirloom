# 08 · 费用清单

> 实施本方案所需的材料费用明细，供执行时参考。
> 价格为 2026 年参考价，以实际购买渠道的价格为准。

| 项目 | 参考价 | 说明 |
|---|---|---|
| 树莓派 Zero v1.3 + LCD HAT + 摄像头 + SD 卡 | $50–70 | 组装 SeedSigner 签名器 |
| 304 不锈钢板 + 钢字码冲子套装 | $20–40 | 或成品助记词钢板套件，约 $80–100 |
| 过塑 + 激光打印 | ~$5 | SeedQR 与密码纸条 |
| 本地加密登记 App（可选） | 视产品而定 | 仅用于记录位置/步骤并导出加密备份；也可用纸笔 + 独立加密压缩包替代 |
| SeedSigner / Sparrow 软件 | 免费 | 开源软件 |
| **总计** | **约 $80–180** | **一次性，之后无年费** |

可选支出：银行保险箱年费（因地区与银行而异），
仅在选择银行作为三地存放之一时产生，非必需。

若使用手头闲置设备（如旧手机作应急签名器、旧电脑跑 Sparrow），
新增花费仅剩钢板与打印部分，**可接近于零** —— 本方案的成本
主要来自"新购专用硬件"这一选择，而非方案本身。

年度维护成本：0（年度演练不产生费用）。
