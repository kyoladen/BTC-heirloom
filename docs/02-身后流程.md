# 02 · 身后流程（家人视角）

> 写给家人的操作手册。第一页不是技术，是人。

## 第 0 步：先别慌

1. 先联系 __________（填写一位懂流程的亲友/顾问电话）
2. 不要告诉外人家里有比特币，不要在网上搜索"如何卖掉继承的比特币"并按陌生人说的做
3. 所有步骤都不着急，币在链上不会跑，**慢慢来，做一步确认一步**

## 第 1 步：取回 Vault 密码（三处任取其一）

- 亲属A家：__________（地址/联系方式）
- 亲属B家：__________（只说是"代保管的重要文件"，对方不知道用途）
- 律师处：__________（姓名/电话）

拿到的是**一张过塑纸条**，上面是一串 14 位以上的乱码 —— 这就是 Vault 密码。
纸条本身不是钥匙，丢了也不怕，但请妥善保管。

## 第 2 步：解密手机里的 Vault 文件

1. 打开手机里的登记 App（图标：____）
2. 找到最新版 `.vault` 备份（看**时间戳**，取最新的）
3. 输入第 1 步拿到的密码解密
4. 解密后你会看到：
   - BIP39 口令（一串字符，**单独无用**，必须配合第 3 步）
   - 钢板 / SeedQR 的存放位置
   - 恢复教程（本手册的详细版，含截图）

## 第 3 步：取回种子材料（三处任取其一）

- 家里保险柜：__________
- 银行保险箱：__________（需走继承公证，耗时以月计，不着急用这处）
- 老家藏匿点：__________

拿到**钢板**（刻着 24 行编号+字母）或 **SeedQR 过塑纸**（二维码）任其一即可。

## 第 4 步：恢复钱包，转移资产

1. 在一台干净的电脑上安装 Sparrow（官网下载，教程附件里有步骤截图）
2. 新建钱包 → "从助记词恢复" → 输入钢板上的 24 个单词
   （每行前 4 字母唯一，Sparrow 会自动补全；或用 SeedSigner 扫 SeedQR）
3. 输入第 2 步得到的 BIP39 口令（注意大小写）
4. 恢复成功后，核对首个收款地址与教程里记录的一致
5. **第一时间把币转到你自己新建的钱包**（新种子、新口令），不要长期用恢复出来的旧钱包

## 第 5 步：之后的事（同样重要）

- 咨询律师：正式遗嘱、继承公证
- 咨询税务师：比特币继承的申报纳税（部分司法辖区继承税率很高，不可忽视）
- 旧的钢板/纸条/密码全部销毁或作废
