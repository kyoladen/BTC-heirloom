# 07 · Multisig 升级路径（可选）

> 本方案默认单签+口令。如果你愿意为家人多做一次教程，
> 2-of-3 multisig 能把"丢一处"从"没事"升级为"毫发无损"，综合评分可再上一个台阶。

## 2-of-3 配置建议（三把钥匙全在自己手里，异地存放）

- 钥匙 A：SeedSigner（家里）—— 日常签名用
- 钥匙 B：第二个种子，钢板（银行保险箱）
- 钥匙 C：第三个种子，SeedQR（老家/亲属家）

任意两把签名即可花币：

- 丢一把 → 剩下两把照样花，随后把币转到新地址作废旧钥匙
- 被偷一把 → 单把钥匙打不开
- 身后 → 家人按教程凑两把即可继承，无需你的大脑参与

## 新增保管物：描述符（Descriptor）

Multisig 特有：`wsh(multi(2, keyA, keyB, keyC))` 一类输出描述符。
它不是密钥（公开无妨），但**丢了钱包软件就不知道如何组装三把钥匙**。

- Sparrow 建完钱包会导出描述符文本，多存几份（可明文，随 vault 分发）
- 恢复时：导入三个种子 + 描述符，缺一不可

## 代价

1. 家人恢复门槛更高：三个种子 + 描述符，教程要写更细
2. 手续费略高（签名数据更大）
3. 三个种子都要做钢板/备份，工作量 ×3（可只给 A、B 做钢板，C 用纸+过塑）

## 升级步骤（已有本方案基础时）

1. 生成三个新种子（流程同 [01](./01-生前流程.md) 1.3–1.5）
2. Sparrow 新建 2-of-3 钱包，导出描述符，多份备份
3. 小额测试：收 → 花（凑两把签名）→ 用描述符+三种子完整恢复验证
4. 大额转入新地址，旧单签钱包清空作废
5. 更新 vault：三把钥匙位置 + 描述符 + 新教程，重新分发
